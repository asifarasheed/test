HTML Tags & Elements Reference

A practical reference to common HTML elements, forms, lists, tables, links, images, media, semantic layout, attributes, accessibility, and obsolete tags—with descriptions and examples.

How to use this guide

HTML (HyperText Markup Language) describes the structure and meaning of web content. Most elements use an opening tag, content, and a closing tag. Void elements—including img, meta, input, and br—do not have closing tags.

Scope note: No static guide can promise every possible attribute value, browser-specific feature, or future web-platform addition. This file covers the main current HTML elements and common website attributes, with important obsolete tags identified. Check current browser support and security requirements for production work.

Accessibility essentials

  • Use semantic elements for their intended meaning and keep headings in a logical hierarchy.
  • Give informative images meaningful alt text; use alt="" for decorative images.
  • Associate every form field with a visible label. Placeholder text is not a replacement for a label.
  • Use anchors for navigation and buttons for actions; ensure interactive features work by keyboard.
  • Use table headers and appropriate scope for tabular data.
  • Provide captions/transcripts for media where appropriate and captions for video when needed.
  • Use ARIA only when native HTML semantics are insufficient. Incorrect ARIA can make accessibility worse.
  • Check contrast, focus visibility, zoom/reflow, and screen-reader behavior; automated checks alone are not enough.

Useful starter examples

Basic HTML page

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My page</title>
  <meta name="description" content="A short page description.">
  <link rel="stylesheet" href="styles.css">
  <script src="app.js" defer></script>
</head>
<body>
  <header><h1>Welcome</h1></header>
  <nav aria-label="Main navigation"><a href="/">Home</a></nav>
  <main><section><h2>About</h2><p>A paragraph.</p></section></main>
  <footer><small>© 2026 Example</small></footer>
</body>
</html>

Form example

<form action="/contact" method="post">
  <label for="name">Your name</label>
  <input id="name" name="name" autocomplete="name" required>
  <label for="email">Email</label>
  <input id="email" name="email" type="email" autocomplete="email" required>
  <label for="message">Message</label>
  <textarea id="message" name="message" rows="5" required></textarea>
  <button type="submit">Send message</button>
</form>

Table example

<table>
  <caption>Product prices</caption>
  <thead><tr><th scope="col">Product</th><th scope="col">Price</th></tr></thead>
  <tbody><tr><td>Notebook</td><td>$4</td></tr></tbody>
</table>
  • Use CSS for presentation and JavaScript for behavior; HTML communicates structure and meaning.
  • Validate markup, test across browsers, and inspect keyboard accessibility.
  • Never trust client-side validation alone; validate and sanitize submitted data on the server.
  • Use HTTPS in production and avoid inserting untrusted HTML directly into pages.
